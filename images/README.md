# Reference Images

This directory holds reference imagery for the parallax depth fields aesthetic.

Suggested categories to populate:
- `terminator_hud/`    — stills from T1/T2 showing the red-readout POV HUD
- `thermal/`           — FLIR camera samples, Predator vision stills
- `bokeh/`             — anamorphic bokeh examples, Saul Leiter photography
- `glsl_renders/`      — output screenshots from the shaders in `/code`
- `chromatic/`         — real-world chromatic aberration examples (fast lenses, cheap optics)

All images in this directory are for **reference and research purposes only**.
